# Reporting Issues

**Experimental preview.** Implemented capabilities and test evidence are described separately. Physical N5000 performance gains, complete GPU support and production readiness are **not verified**. Native APT publication is **BLOCKED** on [signing setup](https://github.com/samuelindra123/xynoos-hypercore/issues/36); Wiki publication is tracked in [#37](https://github.com/samuelindra123/xynoos-hypercore/issues/37). These maintained sources do not claim a live Wiki or APT endpoint.

Search [existing issues](https://github.com/samuelindra123/xynoos-hypercore/issues) first. Include the objective, OS/kernel/architecture, package source/version, exact source SHA and workflow/release URL when known, reproduction steps, expected/actual result, redacted evidence, missing work and acceptance criteria.

Classify status as PASS, FAIL, BLOCKED or NOT TESTED. Separate software defects from unavailable hardware/credentials. Do not attach private keys, tokens, full user data or unreviewed diagnostic process lists. #36 tracks first signed publication; #37 Wiki initialization; #38 historical integration; #17–#22 preserve safety/physical/provenance follow-ups.
