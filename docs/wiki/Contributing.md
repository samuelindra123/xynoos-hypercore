# Contributing

**Experimental preview.** Implemented capabilities and test evidence are described separately. Physical N5000 performance gains, complete GPU support and production readiness are **not verified**. Native APT publication is **BLOCKED** on [signing setup](https://github.com/samuelindra123/xynoos-hypercore/issues/36); Wiki publication is tracked in [#37](https://github.com/samuelindra123/xynoos-hypercore/issues/37). These maintained sources do not claim a live Wiki or APT endpoint.

Contributions should state the problem, resulting behavior, evidence and remaining limitations. Keep experimental/physical claims scoped. Preserve existing source, original branding, installer trust anchors and release history.

Every completed task must be committed and pushed. New PRs must be open Ready for Review (`draft=false`), with implementation, validation, evidence and limitations. Document unfinished work in searched/deduplicated GitHub Issues. Do not force-push, rewrite shared history, delete branches or bypass protection. Merge only reviewed completed work with required CI passing; close superseded work with exact replacement references. Never claim a publication, test or push without read-back verification.

See [project contribution guidance](https://github.com/samuelindra123/xynoos-hypercore/blob/main/README.md#direction-and-contributing), [issues](https://github.com/samuelindra123/xynoos-hypercore/issues) and [historical resolution](https://github.com/samuelindra123/xynoos-hypercore/blob/main/docs/maintenance/HISTORICAL-PR-RESOLUTION.md). Wiki edits originate in docs/wiki and are published using the history-preserving publisher after initialization.
