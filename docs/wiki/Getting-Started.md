# Getting Started

**Experimental preview.** Implemented capabilities and test evidence are described separately. Physical N5000 performance gains, complete GPU support and production readiness are **not verified**. Native APT publication is **BLOCKED** on [signing setup](https://github.com/samuelindra123/xynoos-hypercore/issues/36); Wiki publication is tracked in [#37](https://github.com/samuelindra123/xynoos-hypercore/issues/37). These maintained sources do not claim a live Wiki or APT endpoint.

For a current published binary, use the signed standalone preview described in the existing [installation guide](https://github.com/samuelindra123/xynoos-hypercore/blob/main/docs/INSTALL.md). It is separate from APT. For Debian packages, first read [[Native APT Installation|Native-APT-Installation]] and [[Direct Debian Installation|Direct-Debian-Installation]]; neither channel is advertised as published until verified.

Choose a single command path with `type -a xynoos`. `/usr/bin/xynoos` belongs to dpkg/APT; `~/.local/bin/xynoos` belongs to the rootless manager. Read [[Quick Start|Quick-Start]] before collecting telemetry.
