# Xynoos HyperCore

**Experimental preview.** Implemented capabilities and test evidence are described separately. Physical N5000 performance gains, complete GPU support and production readiness are **not verified**. Native APT publication is **BLOCKED** on [signing setup](https://github.com/samuelindra123/xynoos-hypercore/issues/36); Wiki publication is tracked in [#37](https://github.com/samuelindra123/xynoos-hypercore/issues/37). These maintained sources do not claim a live Wiki or APT endpoint.

Xynoos investigates Linux resource telemetry, deterministic policy and cooperative owned-memory research. The supported product path runs on demand and does not start a tuning daemon.

Start with [[Getting Started|Getting-Started]], [[Installation]], [[System Safety Model|System-Safety-Model]] and [[Known Limitations|Known-Limitations]]. Package/release status is in [[Package Distribution|Package-Distribution]].

Evidence vocabulary: **Implemented** means code exists; **CI tested** names a hosted run; **Cloud tested** identifies a cloud environment; **Physical tested** requires actual hardware evidence. **Not implemented**, **Not verified**, **BLOCKED**, **FAIL** and **NOT TESTED** must not be promoted to success. Earlier operator-supplied laptop observations are not independent physical verification.
